# مرسم — El Marsem Menu Digital

Menu digital mobile-first pour le restaurant **مرسم** (Didouche Mourad).

## Fonctionnalités
- Menu bilingue FR / AR avec RTL
- Recherche en temps réel
- Navigation par catégories (sticky + scrollspy)
- Modale détail plat
- Administration locale protégée par mot de passe (`Admin2026`)
- QR codes et page chevalet imprimable
